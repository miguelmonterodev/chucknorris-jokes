# Chuck Norris Jokes
A website using the Express/Node.js platform, with the Axios HTTP client, that integrates a public API from the https://api.chucknorris.io/ to get Chuck Norris random jokes. The website interacts with the API, retrieve data, and present it in a user-friendly manner.

## How to start the server
- Install Node JS, a tool for executing JS code outside of the browser (visit: https://nodejs.org).
- To install third party packages open the Terminal and run npm command:
    -- $ npm install
- Install nodemon to enhance developer workflow:
    -- $ npm install nodemon --sav-dev
    -- Make sure the script in package.json: {"start": "nodemon app.js"} is there.
- Run the server 
    -- $ npm run start
